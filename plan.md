This is the plan explaining what were building in the smart-crop project.

I have a collection of landscape photos I'm working with in lightroom cloud. They are mostly 3:2 aspect ratio with some the portrait version of that 2:3 and a handful from my drone which are 4:3. My current workflow involves moving them from WIP to Done WIP when I finish editing them. Then I go through each one and make several crops of it for various aspect ratios and export each of those to specific folders where each folder only contains a single aspect ratio. This makes it easy for me to gather all my exports for TV ratio or ipad ratio or phone screen ratio etc. This process takes a lot of time and is mindless so this project is an attempt to automate that.

The idea is I will export the full resolution uncropped JPEG at max quality. Then a locally hosted Qwen LLM model with vision capabilities will power a locally running agent that will look at the image and make a determination of which aspect ratios are applicable to the image (not every image looks good for every aspect ratio). Once the determination is made it will use tool calls to run python scripts which will produce the desired crops and place those files in the appropriate folders. 

The pictures in question are virtually entirely landscape photography. There is no concern of how a person fits in the frame. Ideally I would keep these at full resolution but since the aspect ratios don't align something will have to be cut off. For a 3:2 image this is primarily deciding if we cut off the top of the frame or the bottom or a bit of both and keep the middle. For cropping to 4:3 from 3:2 for say iPad format then its the same problem with the sides. iPhone format is a bit tougher since its a portrait orientation. Often only pictures that were originally portrait can be cropped in a way that makes sense but occasionally there is an opportunity to crop a 3:2 image in an interesting way by taking the middle third of it or something like that.
